# snake-
# 贪吃蛇小游戏 (C++ Console Snake Game)

这是我在大一期间独立开发的一个基于 C++ 的控制台贪吃蛇游戏，也是我的第一个完整项目。

## 🎮 游戏特色 (Features)
* 包含完整的开始菜单、游戏说明和退出功能
* 支持 WASD 键控制蛇的上下左右移动
* 食物随机生成，且不会重叠在蛇身上
* 吃食物会增加长度和分数
* 撞墙或撞到自己会游戏结束
* 支持按 V 加速、按 B 减速

## 🛠️ 技术栈 (Tech Stack)
* **语言**: C++
* **环境**: Windows / Visual Studio
* **使用的库**: `<iostream>`, `<conio.h>`, `<windows.h>` (用于控制台光标控制和键盘输入)

## 🚀 如何运行 (How to Run)
1. 下载或克隆本仓库
2. 使用 Visual Studio 打开 `snake.cpp`
3. 编译并运行 (Ctrl + F5)
4. 根据菜单提示进行游戏
